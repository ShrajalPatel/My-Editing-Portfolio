# 🎥 Savvy Shrajal — Creative Video & Photo Editor Portfolio

Welcome to my personal creative portfolio website!  
This project showcases my video editing, photo retouching, and design work — including cinematic reels, anime edits, and digital art banners.

---

## 🖼️ Overview

This website serves as an **interactive portfolio** where visitors can:
- Explore my **video editing** and **photo design** projects
- View **high-quality previews** directly on the site
- Learn **about my creative process**
- **Contact me** for collaboration opportunities

Built using **React + TypeScript + TailwindCSS + Framer Motion**, the site delivers a smooth, responsive, and visually engaging experience.

---

## ⚙️ Tech Stack

| Category | Technologies |
|-----------|---------------|
| **Frontend Framework** | React + TypeScript |
| **Styling** | Tailwind CSS, shadcn/ui |
| **Animations** | Framer Motion |
| **Build Tool** | Vite |
| **Media Format** | `.webm (AV1)` for optimized performance with `.mp4` fallback |
| **Hosting (planned)** | GitHub Pages / Vercel |
